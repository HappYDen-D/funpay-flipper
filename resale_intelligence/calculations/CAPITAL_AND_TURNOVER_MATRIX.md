# Капитал, резерв и распределение корзины

## Денежные определения

Закупка B — фактическое списание. Поступление N — сумма, начисленная продавцу. Прибыль успешной сделки Π = N − B − c, где c — затраты обработки. ROI = Π/B, маржа по поступлению = Π/N.

Для интерфейса `seller_net` N равняется указанной цене; для `buyer_gross` нужен измеренный эффективный процент удержаний. Обоснование ценовых баз и источники находятся в [разделах 2 и 5 исследования](../research/RESEARCH_REPORT.md).

## Пилотная политика риска

| Ограничение | Доля капитала | При капитале 350 ₽ |
|---|---:|---:|
| Денежный резерв | 15%, минимум 50 ₽ | 52,50 ₽ |
| Одна покупка | 15% | 52,50 ₽ |
| Все открытые товары одной категории | 40% | 140 ₽ |
| Все открытые товары одного поставщика | 25% | 87,50 ₽ |

Пороговые значения выбраны для ограниченного пилота. Это не оптимум рынка. Несколько лотов одного поставщика суммируются; существующие позиции уменьшают доступную экспозицию.

## Задача распределения

Максимизировать Σ xᵢ E[Πᵢ] при целых xᵢ ≥ 0, сумме закупки не выше доступных денег за вычетом резерва, лимитах предложения, категории, поставщика и одиночной покупки. Позиции с отрицательным ожидаемым результатом исключаются.

`capital_allocation.allocate` решает небольшой статический вариант полным перебором до миллиона комбинаций. Суммы на входе — копейки. Проверенные котировки обозначаются `verified=True`; исторические цены не получают этот статус автоматически. Модель использует переданные вероятности и не оценивает их по рынку.

Нельзя обещать, что статически лучшая корзина оптимальна по времени: для сравнения разных сроков удержания нужен симулятор. Резерв не отменяет ограничение аккаунта на оплату — деньги могут существовать на балансе, но быть недоступны для новой покупки.
